# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-09-24

### Added

- Initial public release of Ink, a static gamified Python course.
- Eleven-track curriculum with published lessons and exercises, cited sources
  and build-time content validation.
- In-browser CPython 3.14 execution through Pyodide, including code running,
  exercise tests, drafts and console output.
- Local progress system with XP, levels, streaks, badges, profile and
  leaderboard standing stored in the browser.
- Monochrome editorial design system, reading controls, accessibility skip
  link, error boundaries, 404 page and status page.
- SEO routes for robots and sitemap, generated Open Graph and Twitter images,
  privacy and terms pages.
- CI workflow, dependency automation, issue forms, pull request template,
  contribution guide, security policy, code of conduct and support policy.
- Dual licensing package: MIT for software, CC BY-NC-SA 4.0 for original
  course content, with third-party notices.
