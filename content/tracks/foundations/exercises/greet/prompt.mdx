## The task

Write a function `greet` that takes a name and returns the string
`"Hello, <name>!"`, where `<name>` is replaced by the name you were given.

```python
greet("Ada")  # "Hello, Ada!"
```

## Rules

- Return the greeting. Do not print it.
- An empty name is still a valid name: `greet("")` returns `"Hello, !"`.
- Names with spaces or unusual characters must be returned unchanged.

## Before you run

Say out loud what `greet("Grace")` should return. Then run the tests and
compare.
