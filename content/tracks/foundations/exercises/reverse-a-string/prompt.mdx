## The task

Write `reverse_string(text)` that returns the characters of `text` in reverse
order.

```python
reverse_string("python")  # "nohtyp"
```

## Rules

- Return a new string. Do not modify the input.
- An empty string returns an empty string.
- A single character returns itself.
- Spaces and punctuation are characters too: `reverse_string("ab c")` is
  `"c ba"`.

## Two solutions worth writing

1. Build the result one character at a time with a loop.
2. Use slicing, which you met in lesson 6.

Write the loop version first, then the slice version, then delete whichever one
you cannot explain out loud in one sentence.
