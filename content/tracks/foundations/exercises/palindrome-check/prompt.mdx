## The task

Write `is_palindrome(text)` that returns `True` when the text reads the same in
both directions.

```python
is_palindrome("A man, a plan, a canal: Panama")  # True
```

## Rules

- Ignore case.
- Ignore every character that is not a letter or a digit.
- An empty string, or a string with nothing left after cleaning, is a
  palindrome.

## Build it in two steps

Cleaning and checking are separate problems, and mixing them is why this
exercise is harder than it looks. First produce the normalised text, then
compare it with its reverse.

```python
cleaned = "".join(c for c in text.lower() if c.isalnum())
```
