## The task

Write `largest(a, b, c)` that returns the biggest of the three values.

```python
largest(3, 19, 7)  # 19
```

## Rules

- Do not call `max()`. The point is to practise comparisons.
- Ties are fine: return the value, not which argument it was.
- Works with negative numbers and floats.

## Think first

If you sort a three-item list and take the last value, that is a fine solution —
but the built-in-free version teaches the comparison chain from lesson 7. Write
that one, then write the sort version, then compare them on readability.
