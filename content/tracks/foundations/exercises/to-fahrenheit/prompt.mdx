## The task

Write `to_fahrenheit(celsius)` to convert degrees Celsius to degrees Fahrenheit
using the formula

```text
F = C * 9/5 + 32
```

## Rules

- Return a number, not a string.
- `0` Celsius is `32` Fahrenheit. `100` Celsius is `212` Fahrenheit.
- Negative temperatures must work.
- Do not round. Return the raw result; formatting is somebody else's job.

## Watch out

In Python `9 / 5` is `1.8`, but `9 // 5` is `1`. Which one does the formula
need?
