## The task

Write `last_character(text)` returning the final character, or `""` when the
string is empty.

```python
last_character("python")  # "n"
last_character("")        # ""
```

## Rules

- Return the character, not its position.
- Do not strip whitespace: `last_character("hello ")` is a space.
- A one-character string returns itself.

## The trap

`text[-1]` is the answer for every non-empty string and raises `IndexError` for
the empty one. Guard the case, and do not reach for a try/except when an `if`
is clearer.
