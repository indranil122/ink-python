## The task

Write `first_word(sentence)` returning the first word of the sentence.

```python
first_word("  learn python every day  ")  # "learn"
```

## Rules

- Ignore leading and trailing whitespace and repeated internal spaces.
- An empty or whitespace-only sentence returns an empty string.
- Words are separated by whitespace, not by commas.

## Do it in one line

`str.split()` with no argument already does the cleaning for you, and a list of
words is one index away from the answer.

<Callout kind="try" title="Then write last_word">
  The companion function is `sentence.split()[-1]`, but that raises
  `IndexError` on an empty list. Decide how you want an empty sentence handled
  and write the branch that makes it safe.
</Callout>
