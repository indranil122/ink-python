## The task

Write `is_even(number)` that returns `True` when `number` is divisible by two and
`False` otherwise.

```python
is_even(4)   # True
is_even(7)   # False
```

## Rules

- Return a boolean, not the strings `"True"` or `"False"`.
- Zero is even.
- Negative numbers are allowed: `-3` is odd.

## The intended solution

There is a built-in for this in real code, but the exercise is about the
operator. Which arithmetic operator from lesson 5 tells you whether a division
came out whole?
