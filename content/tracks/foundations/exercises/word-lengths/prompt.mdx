## The task

Write `word_lengths(sentence)` returning a list with the length of each word.

```python
word_lengths("learn python")  # [5, 6]
```

## Rules

- Ignore extra whitespace between words.
- An empty sentence returns an empty list.
- Punctuation counts as part of the word.

## The comprehension

Lesson 9 showed loops; this is the shape that replaces most of them:

```python
[word for word in sentence.split()]
```

Put the transformation inside and you are done in one line. Write the loop
version first so you can compare the two.
