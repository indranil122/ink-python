## The task

Write `digit_sum(number)` that returns the sum of the digits of a non-negative
integer.

```python
digit_sum(1234)  # 10
digit_sum(0)     # 0
```

## Rules

- No `str()`, no `sum()` over characters, no `math` tricks. Arithmetic only.
- The input is non-negative.
- Zero is a valid input and its digit sum is zero.

## The operator

`number % 10` gives the last digit. `number // 10` removes it. A loop over
those two operations solves the problem without ever turning the number into
text.

<Callout kind="try" title="Work one step by hand">
  ```python
  number = 1234

  print(number % 10)
  print(number // 10)
  ```

  Run it. Those two lines are the entire algorithm, repeated until the number
  is gone.
</Callout>
