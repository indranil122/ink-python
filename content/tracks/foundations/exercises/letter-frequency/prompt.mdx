## The task

Write `letter_counts(text)` returning a dictionary mapping each letter to the
number of times it appears.

```python
letter_counts("banana")  # {"b": 1, "a": 3, "n": 2}
```

## Rules

- Lowercase the text first, so case does not create separate entries.
- Ignore anything that is not a letter: spaces, digits, punctuation.
- An empty string returns an empty dictionary.
- Include letters that appear once. Omit letters that do not appear.

## The accumulator pattern

This is the first exercise that builds a dictionary step by step, and the shape
appears everywhere in real code:

```python
counts = {}
for character in text:
    counts[character] = counts.get(character, 0) + 1
```

`dict.get(key, default)` is the safe way to read a key that might be missing.
Plain `counts[key]` would raise `KeyError` on the first character.
