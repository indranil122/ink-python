## The task

Write `classify_grade(score)` returning a letter grade.

| Score | Grade |
| --- | --- |
| 90–100 | `A` |
| 80–89 | `B` |
| 70–79 | `C` |
| 60–69 | `D` |
| below 60 | `F` |

## Rules

- Return a single letter string.
- 90 returns `A`, 89 returns `B`, 60 returns `D`, 59 returns `F`.
- Scores above 100 also return `A`.

## The lesson

Write the branches from the highest threshold down. If you write `if score >=
60` first, every passing student gets a `D` and the rest of the chain is dead
code. Order is the whole exercise.
