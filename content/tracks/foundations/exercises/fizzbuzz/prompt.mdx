## The task

Write `fizzbuzz_line(number)` that returns the classic string for one number.

- Divisible by 3 **and** 5: `"FizzBuzz"`
- Divisible by 3 only: `"Fizz"`
- Divisible by 5 only: `"Buzz"`
- Otherwise: the number as a string

```python
fizzbuzz_line(15)  # "FizzBuzz"
fizzbuzz_line(7)   # "7"
```

## Rules

- Return a string every time, including for plain numbers.
- Zero is divisible by everything, so `fizzbuzz_line(0)` is `"FizzBuzz"`.
- Negative numbers follow the same rules: `fizzbuzz_line(-3)` is `"Fizz"`.

## The lesson

This exercise exists to prove one point: **condition order matters**. If you
test for divisibility by 3 first and return `"Fizz"` immediately, number 15
can never reach the `"FizzBuzz"` branch. Check the most specific case first.
