## The task

Write `is_leap_year(year)` that returns `True` when the year is a leap year in
the Gregorian calendar.

```python
is_leap_year(2024)  # True
is_leap_year(1900)  # False
```

## Rules

- A year is a leap year if it is divisible by 4,
- except years divisible by 100,
- except again for years divisible by 400, which are leap years.

So 2024 is a leap year, 1900 is not, and 2000 is.

## The trap

The century rules are exactly what a single `year % 4` check gets wrong. Write
the conditions as a chain, most specific first, and test 1900 and 2000
explicitly before you submit.

<Callout kind="try" title="Trace the three cases">
  ```python
  print(2024 % 4, 2024 % 100, 2024 % 400)
  print(1900 % 4, 1900 % 100, 1900 % 400)
  print(2000 % 4, 2000 % 100, 2000 % 400)
  ```

  One line of output per year. The leap year is the one divisible by 4 but
  *not* by 100, or divisible by 400.
</Callout>
