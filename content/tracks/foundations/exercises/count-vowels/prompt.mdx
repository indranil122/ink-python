## The task

Write `count_vowels(text)` that returns the number of vowels in `text`.

```python
count_vowels("Hello")  # 2
```

## Rules

- Count `a`, `e`, `i`, `o`, `u`.
- Ignore case: `count_vowels("AEIOU")` is `5`.
- Ignore anything that is not a letter, including spaces, digits and
  punctuation.
- An empty string has zero vowels.

## Two ways to solve it

There is more than one correct answer, and comparing them is the exercise. Try
a loop first. Then try the `for` loop's cousin that filters a string down to the
characters you care about, and count what is left.

```python
vowels = "aeiou"
clean = "".join(character for character in text.lower() if character in vowels)
```
