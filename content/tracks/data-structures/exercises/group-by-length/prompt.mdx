## The task

Write `group_by_length(words)` returning a dictionary from length to the list of
words of that length.

```python
group_by_length(["a", "bb", "cc"])  # {1: ["a"], 2: ["bb", "cc"]}
```

## Rules

- Words keep their input order inside each group.
- An empty list returns an empty dictionary.
- Duplicated words are kept.

## The tool

`setdefault` turns "find or create" into one line:

```python
groups.setdefault(len(word), []).append(word)
```

This is the standard grouping pattern. Learn it here and you will write it in
Track 9 for every `groupby` you ever need.
