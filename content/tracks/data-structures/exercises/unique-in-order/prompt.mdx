## The task

Write `unique_in_order(values)` that removes **consecutive** duplicates, keeping
the first item of every run.

```python
unique_in_order([1, 1, 2, 2, 3, 1])  # [1, 2, 3, 1]
```

Note the final `1`: it is kept because it does not follow another `1`. This is
not full deduplication — that would be a set.

## Rules

- Preserve order.
- An empty input returns an empty list.
- Work for any hashable value, not just numbers.

## The one-line version

`itertools.groupby` groups consecutive equal items. The idiomatic solution
returns the first value of each group, which is a good lesson in reading the
standard library before writing loops yourself.
