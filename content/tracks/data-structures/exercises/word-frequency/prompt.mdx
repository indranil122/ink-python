## The task

Write `word_frequency(text)` returning `(word, count)` pairs sorted by count,
highest first.

```python
word_frequency("a b a")  # [("a", 2), ("b", 1)]
```

## Rules

- Compare case-insensitively: `A` and `a` are the same word.
- Ignore punctuation entirely: `"a, b"` is two words.
- Ties keep alphabetical order.
- An empty or punctuation-only string returns an empty list.

## The two halves

Counting is a dictionary accumulator. Sorting is `sorted(pairs, key=...)`. The
tie-break is the interesting part: sort by count descending, then by word
ascending, which needs a tuple key.

```python
sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
```
