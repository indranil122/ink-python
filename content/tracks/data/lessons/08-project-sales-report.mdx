## The question first

"Which regions are growing, and by how much?" Every step below exists to answer
that. A project without a question becomes a pile of charts nobody reads.

## Load

```python
import pandas as pd

orders = pd.read_csv(
    "orders.csv",
    parse_dates=["order_date"],
    dtype={"order_id": "string", "region": "string"},
)
regions = pd.read_csv("regions.csv")   # region -> country, segment
print(orders.shape, regions.shape)
```

## Clean

```python
before = len(orders)

orders = orders.drop_duplicates()
orders = orders.dropna(subset=["order_date", "total", "region"])
orders = orders[orders["total"] > 0]
orders["region"] = orders["region"].str.strip().str.title()

print(f"dropped {before - len(orders)} rows")
```

The printed count belongs in the output. Anyone reading the report can see how
many rows did not survive, which is the difference between a finding and a
guess.

## Join

```python
data = orders.merge(regions, on="region", how="left", validate="m:1")
print(data.shape, data["country"].isna().sum())
```

`validate="m:1"` makes a bad join fail loudly instead of multiplying rows.

## Aggregate

```python
monthly = (
    data.set_index("order_date")
        .sort_index()[["total"]]
        .resample("ME")
        .sum()
)

year_over_year = monthly["total"].pct_change(12).mul(100).round(1)
summary = pd.DataFrame({
    "revenue": monthly["total"].round(2),
    "yoy_pct": year_over_year,
}).dropna()

print(summary.tail())
```

## Plot one thing

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(10, 4))
ax.plot(monthly.index, monthly["total"], label="Revenue")
ax.set_title("Monthly revenue")
ax.set_ylabel("Revenue (GBP)")
ax.legend()
fig.savefig("revenue.png", dpi=150, bbox_inches="tight")
```
