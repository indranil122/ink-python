## A table with labels

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["ada", "alan", "grace"],
    "age": [36, 41, 45],
    "score": [100.0, 91.5, 98.0],
})

print(df.shape)   # (3, 3)
print(df.dtypes)
```

Each column is a Series with one dtype; each row is indexed by default with
0, 1, 2.

## Selecting

```python
df["name"]                    # one column, a Series
df[["name", "score"]]         # two columns, a DataFrame
df.loc[0, "name"]             # one cell, by label
df.iloc[0, 0]                 # one cell, by position
df[df["age"] > 38]            # rows matching a condition
```

`.loc` is by label, `.iloc` is by position. Confusing them is the most common
pandas error, and the fix is to decide which one you mean before you type.

<Callout kind="watch" title="Chained assignment does not work">
  ```python
  df[df["age"] > 38]["score"] = 0     # SettingWithCopyWarning, may do nothing
  df.loc[df["age"] > 38, "score"] = 0  # correct
  ```

  Filtering produces a copy that pandas cannot guarantee is a view. Always
  assign through `.loc` in one step.
</Callout>

## The index

```python
df = df.set_index("name")
print(df.loc["ada"])
```

The index is the row label. It is used by `loc`, it survives sorting and joining,
and if it has duplicates, `loc` returns several rows rather than raising — which
is a bug you may not notice.

## Summarising

```python
print(df.describe())
print(df["score"].mean())
print(df.groupby("age").size())
```

`describe` gives count, mean, standard deviation, min, quartiles and max, which
is the first thing to look at with any new data set.

<Callout kind="try" title="Compare loc and iloc">
  Sort a DataFrame by a column, then compare `df.loc[0]` with `df.iloc[0]`.
  After sorting, the label 0 and the position 0 are usually different rows.
  That difference is the whole reason both accessors exist.
</Callout>

<Callout kind="recap" title="Recap">
  `pd.DataFrame` is labelled columns of typed Series with a row index. Use
  `.loc` for labels and `.iloc` for positions, assign through `.loc` in one
  step, and check `describe()` before you trust any column.
</Callout>
