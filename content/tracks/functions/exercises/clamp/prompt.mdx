## The task

Write `clamp(value, low, high)` returning `value` restricted to the inclusive
range `[low, high]`.

```python
clamp(15, 0, 10)   # 10
clamp(-5, 0, 10)   # 0
clamp(5, 0, 10)    # 5
```

## Rules

- Values equal to a bound are returned unchanged.
- Reversed bounds raise `ValueError`: `clamp(5, 10, 0)` is a programming error,
  not something to silently fix.

## The shape

```python
if low > high:
    raise ValueError("low must not exceed high")
if value < low:
    return low
if value > high:
    return high
return value
```

The two comparisons are ordered rather than combined, which makes each branch
obvious. Then write the one-line version with `min` and `max`, and decide which
you would rather read at the call site.

<Callout kind="try" title="Two versions">

  place in both.
</Callout>
