## The task

Write `apply_twice(function, value)` that passes `value` through `function` twice
and returns the result.

```python
apply_twice(lambda n: n + 3, 1)   # 7
```

The first argument is a function, which is the point: your parameter is annotated
as a callable and called like any other object.

## Rules

- The function is called exactly twice, not in a loop.
- Return the value from the second call, even if the first call returns
  something unprintable.
- Calling it with a built-in like `str` works too:
  `apply_twice(str.strip, "  x  ")` is `"x"`.

## Annotate it

```python
from collections.abc import Callable

def apply_twice(function: Callable[[int], int], value: int) -> int:
    return value
```

The annotation is the documentation *and* what a type checker uses to prove you
call it correctly.
