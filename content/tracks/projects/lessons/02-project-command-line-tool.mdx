## The brief

A command line tool that reads a folder of CSV files and prints a summary per
file: row count, date range, and the sum of the first numeric column. Two weeks,
no interface, no database.

## The structure

```text
csv-summary/
  pyproject.toml
  src/
    csv_summary/
      __init__.py
      cli.py
      summary.py
  tests/
    test_summary.py
```

```toml
[project.scripts]
csv-summary = "csv_summary.cli:main"
```

```bash
python -m pip install -e ".[dev]"
csv-summary data/ --column total
```

## One module per responsibility

```python
def summarise(path: Path, column: str | None = None) -> Summary:
    """Read one CSV and return its summary."""
    ...

def render(summary: Summary) -> str:
    """Format one summary for the terminal."""
    ...
```

`summary.py` knows about CSV. `cli.py` knows about arguments and printing.
Neither knows about the other, which is why both are easy to test.

## Errors the user can act on

```python
try:
    summary = summarise(path, column)
except FileNotFoundError:
    print(f"no such file: {path}", file=sys.stderr)
    raise SystemExit(1)
except KeyError as error:
    print(f"column not found: {error}", file=sys.stderr)
    raise SystemExit(1)
```

Name the file, name the column, exit non-zero. A tool that prints a traceback
for a missing column is a tool nobody scripts.
