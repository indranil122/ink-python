# Support

## Getting help

- **Broken lesson or exercise:** open a bug report with the track, lesson or
  exercise slug and what you expected.
- **Content correction:** open a content issue with the URL and a suggested
  fix or source.
- **Feature idea:** open a feature request describing the learner problem, not
  only the implementation.
- **Build, test or contribution help:** search existing issues, then open a
  new issue with your Node.js version and the failing command's output.

## What this project is not

Ink is a static, non-commercial educational site. There is no paid support,
hosted account system or service-level agreement. Progress is stored in your
browser; clearing site data can remove it.

## Security and privacy

Report vulnerabilities according to [SECURITY.md](SECURITY.md). Privacy
questions are answered in [PRIVACY_POLICY.md](PRIVACY_POLICY.md).
